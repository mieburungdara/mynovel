# Plan: Clone web-novel-static-generator dan Buat Situs Novel Multi-Novel

## Goal
Clone repository web-novel-static-generator dari GitHub, setup struktur untuk situs novel yang mendukung multiple novels dan chapters, tambah contoh content, konfigurasi GitHub Actions untuk deploy ke GitHub Pages, dan verify deployment.

## Assumptions
- User punya GitHub account dan repo baru untuk situs ini.
- Repo target adalah GitHub Pages compatible (misal username.github.io atau repo project).
- Content novel akan ditambah sebagai contoh; user bisa replace nanti.
- Tidak ada requirement khusus untuk tema atau fitur tambahan selain multiple novels/chapters.

## Steps

### 1. Clone Repository
- Clone web-novel-static-generator dari https://github.com/Oekaki-Connect/web-novel-static-generator ke lokal directory.
- Push ke GitHub repo baru (misal mynovel.github.io) untuk enable GitHub Pages.

### 2. Setup Content Structure
- Buat folder content/ dengan subfolder per novel (e.g., content/novel1/, content/novel2/).
- Tambah config.yaml per novel dengan metadata (title, author, etc.).
- Tambah file Markdown untuk chapters (e.g., chapter1.md, chapter2.md) dalam setiap subfolder novel.

### 3. Konfigurasi GitHub Actions
- Copy atau edit .github/workflows/deploy.yml dari repo source untuk build dan deploy otomatis ke gh-pages branch.
- Pastikan workflow trigger pada push ke main branch.

### 4. Tambah Contoh Content
- Buat 2 novel contoh dengan 3-5 chapters masing-masing menggunakan Markdown.
- Tambah front page landing dengan list novels.

### 5. Local Testing (Opsional)
- Jalankan generator lokal untuk preview situs.
- Verify struktur file dan navigasi.

### 6. Deploy dan Verify
- Push semua changes ke GitHub.
- Enable GitHub Pages di repo settings, set source ke gh-pages branch.
- Akses situs dan cek multiple novels dan chapters berfungsi.

## Potential Issues
- Jika repo bukan username.github.io, pastikan custom domain setup.
- Build failure jika Python dependencies missing di GitHub Actions – pastikan requirements.txt included.
- Navigasi chapters mungkin perlu tweak jika struktur complex.

## Resources
